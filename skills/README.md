# Cursor skills (any repo)

Install once so Cursor can run these in every project:

```bash
./install.sh
```

That symlinks each folder into `~/.cursor/skills/`.

| Folder | Invoke when |
|--------|-------------|
| [design-system-3-level](design-system-3-level/SKILL.md) | 3-level token system |
| [design-system-2-level](design-system-2-level/SKILL.md) | 2-level token system |
| [css-modules](css-modules/SKILL.md) | Per-component CSS |

Do not copy these into each app’s `.cursor/skills/` unless you want them versioned with that app. Personal install is enough for portability.
